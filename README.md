## Research Overview

This repository documents comprehensive research on AI-enabled social engineering detection, focusing on the development of threat analytics frameworks for identifying and predicting attack patterns using machine learning and artificial intelligence techniques.

## Repository Structure

### 📄 [01_Papers](./01_Papers/)
Research paper PDFs and literature related to social engineering detection and threat analytics.

### 📝 [02_Notes](./02_Notes/)
Reading notes, annotations, and key findings from research literature.

### 💻 [03_Code](./03_Code/)
Python implementations, machine learning models, and experimental code for social engineering detection.

### 📊 [04_Data](./04_Data/)
Datasets used for model training, validation, and evaluation.

### ✍️ [05_Writing](./05_Writing/)
Dissertation chapters, paper drafts, and technical writing.

### 🎤 [06_Presentations](./06_Presentations/)
Slides, posters, and presentation materials for conferences and seminars.
