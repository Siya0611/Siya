- Machine learning models and training scripts
- Data processing and feature engineering
- Detection algorithms and implementations
- Experimental notebooks and analysis

## Requirements

See individual subdirectories for specific dependencies. General requirements:
- Python 3.8+
- scikit-learn, TensorFlow/PyTorch, or similar ML frameworks
- pandas, numpy for data processing
