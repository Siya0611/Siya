# Datasets

This folder contains datasets used in the research on AI-enabled social engineering detection.

## Contents

- Raw datasets for model training and evaluation
- Processed/cleaned datasets
- Synthetic or augmented data
- Dataset documentation and metadata

## Data Usage

- **Confidentiality**: Ensure sensitive data is properly handled according to institutional policies
- **Attribution**: Include source information for all datasets
- **Licensing**: Document data licenses and usage rights

## Dataset Documentation

For each dataset, include:
- Source and collection method
- Data format and structure
- Feature descriptions
- Temporal coverage
- Known limitations or biases
